게임 본체 받기게시판 파일 받기앱스크립트 코드(Code.gs) 받기

205호 방탈출 · 앱스크립트 붙이기 (교사용 안내)

게임이 이미 돌아가는 상태에서, 학생이 쓴 글(STEP 3·4)을 내 구글 시트로 받는 방법입니다. 약 20분.

못 붙여도 괜찮아요. 주소 칸을 비워 두면 게임은 그대로 돌아가는 '간단판'입니다.

키트 구성

파일용도
room205-starter.html게임 본체. 맨 위 shareUrl만 내 주소로 바꿈
room205-starter-board.html내 화면에 띄우는 우리 반 게시판 (주소 한 줄 설정)
Code.gs구글 앱스크립트 코드 (붙여 넣기용)

1단계. 앱스크립트 만들기 (구글 계정에서)

  1. https://script.google.com → 새 프로젝트
  2. 기본으로 있는 코드를 모두 지우고 Code.gs 내용을 전부 붙여 넣기 → 저장(디스크 아이콘)
  3. 위쪽 함수 선택 칸에서 setup 선택 → 실행
  4. 권한 창이 뜨면: 권한 검토 → 내 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 고급 → (프로젝트 이름)으로 이동(안전하지 않음) → 허용
  • 본인이 만든 스크립트라서 나오는 정상 화면이에요.
  1. 내 구글 드라이브에 '205호 공유판 제출' 시트가 생겨요.

2단계. 웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포 → 톱니바퀴 → 웹 앱
  2. 실행: 나 / 액세스 권한이 있는 사용자: 모든 사용자 → 배포
  3. 나온 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사

3단계. 반 코드 정하기

시트 '205호 공유판 제출' → 아래 반코드 탭 → A2부터 한 줄에 하나씩 학급 코드 입력 (예: 3반). 기본값 TEST205는 지우세요.

4단계. 게임에 주소 넣기

room205-starter.html을 메모장 등으로 열면 맨 위에 이렇게 있어요.

window.ROOM205_CONFIG = {

shareUrl: '' ← 따옴표 안에 2단계에서 복사한 주소 붙여 넣기

};

게시판 파일(room205-starter-board.html)에도 var SHARE_URL='' 줄이 있어요. 같은 주소를 넣으세요.

5단계. 사이트로 올리기 → 학생 링크

올린 주소 뒤에 ?c=반코드를 붙여 나눠 주세요. 예: https://내사이트/?c=3반 (코드가 자동으로 채워져요)

게시판: https://내사이트/board.html?c=3반 (파일 이름을 board.html로 올리세요)

수업 중

  1. 학생이 최종 미션 STEP 3·4를 쓰고 우리 반에 보내기
  2. 시트 제출 탭에서 읽고, 공개해도 되는 글은 E열 '승인'에 체크
  3. 게시판 화면에 20초 안에 나타남 (승인한 글만)

자주 하는 실수

  • 코드를 고친 뒤 다시 배포할 때: 「배포 관리 → 연필(수정) → 버전: 새 버전 → 배포」. 「새 배포」를 누르면 주소가 바뀌어 게임이 안 돼요.
  • 주소 끝이 /exec인지 확인 (/dev는 안 됨)
  • 접근 권한을 '모든 사용자'로 하지 않으면 학생 기기에서 안 돼요
  • 학교 네트워크가 script.google.com을 막으면 제출이 안 돼요 → 연수 전에 학생 기기로 확인

개인정보·안전

  • 이름은 받지 않아요. 학생 글은 내 시트에만 쌓여요.
  • STEP 2(개인 경험)는 서버로 보내지 않아요. 학생에게 알려 주세요.
  • 학생에게 "보낸 글은 선생님이 고른 글만 반 친구들에게 보여요"라고 먼저 말해 주세요.
  • 반 코드는 학급 밖에 공유하지 마세요. 수업이 끝나면 시트의 글과 코드를 지우세요.
  • 다른 선생님의 웹 앱 주소를 같이 쓰지 마세요. 학생 글이 그 선생님 시트로 가요.
